# Corpus: Axxiom Safety and Health Policies, Section 2 (v1.0)

- `source.pdf`: the PDF exported from the master Google Doc (sha256 in `manifest.json`).
- `tables.json`: registry of tables that the PDF text layer flattens to one cell per line; ingestion rebuilds them as Markdown.
- `overrides.json`: manual fixes for subsection headings the matcher cannot find (`{"number": "8.6", "page": 56, "line": 30, "note": "..."}`).
- `emergency-playbooks.json`: emergency steps quoted from the manual, used when a message describes an emergency in progress. Draft until approved by the Safety Manager.
- `manifest.json`: generated by `pnpm ingest run`; committed so other packages can read the structure without re-running extraction.
- `review/`: generated review material for the Safety Manager (`structure.md`).

Regenerate with:

```sh
pnpm ingest -- run --pdf corpus/axxiom-s2/v1.0/source.pdf --version-id axxiom-s2-v1.0 --expect-pages 209
```

## Known source issues (fix in the Google Doc, then re-export)

Found while ingesting v1.0. Each one is either worked around in this folder or left visible on purpose.

| TOC entry 20.5 | Reads "Remit-Required Space Entry"; the body heading is "Permit-Required Space Entry". | `overrides.json` points 20.5 at page 170. |
| TOC entry 24.3 | "Driving Position Inventory" has no heading or content in Program 24. | `overrides.json` marks it absent; the assistant will report the topic as not covered. Add the section or remove the entry. |
| Program 18 title | "Lead Awareness" sits alone at the bottom of page 149; the program body starts on page 150. | Handled automatically; a page break before the title would fix it. |
